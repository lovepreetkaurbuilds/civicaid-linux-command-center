# CivicAid Linux Operations Command Center

A practical Linux and Shell learning project built around a fictional NGO/community operations system.

This project demonstrates beginner-to-advanced Linux skills through real command-line workflows, including:

- Linux navigation
- File and folder management
- Text processing
- Shell scripting
- Logs
- Reports
- Backups
- Permissions
- Automation
- Python workflow
- Git/GitHub workflow
- Server-style operations thinking

All data used in this project is fake/sample data only.

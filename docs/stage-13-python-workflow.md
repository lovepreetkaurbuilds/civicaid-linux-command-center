# Stage 13: Python Project Workflow in Linux

This stage connects Linux terminal workflow with Python development and testing.

## Commands practiced

- python3 --version
- pip3 --version
- python3 -m venv .venv
- source .venv/bin/activate
- pip install pytest
- pip freeze > requirements.txt
- python src/civicaid.py
- pytest

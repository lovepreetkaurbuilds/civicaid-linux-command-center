# Stage 16: Shell Scripting Beginner

This stage demonstrates beginner shell scripting using the CivicAid Linux Operations Command Center.

## Concepts learned

- .sh script files
- shebang
- variables
- read input
- if/else
- loops
- functions
- script arguments
- exit codes

## Scripts created

| Script | Purpose |
|---|---|
| scripts/generate_report.sh | Generates the CivicAid daily operations report |
| scripts/backup_data.sh | Creates a timestamped backup folder |
| scripts/search_requests.sh | Searches help requests by keyword |
| scripts/run_health_check.sh | Checks required folders, files, and tools |

## Practical tasks completed

1. Converted manual report generation into a reusable script.
2. Created a beginner backup script.
3. Created a searchable help request script using arguments and read input.
4. Created a health check script using arrays, loops, functions, and if/else.
5. Saved script outputs into report files.

## Real-world meaning

Shell scripts allow Linux users to automate repeated operations such as reports, backups, health checks, searches, deployments, and maintenance tasks.

# Stage 18: Archiving and Compression

This stage demonstrates archiving and compression using the CivicAid Linux Operations Command Center.

## Commands practiced

- tar
- gzip
- zip
- unzip

## Concepts learned

- Archiving combines multiple files/folders into one file.
- Compression reduces file size.
- .tar files are archives.
- .tar.gz files are compressed tar archives.
- .zip files are compressed archives.
- Backups should be tested by extracting them.

## Practical CivicAid tasks completed

1. Created tar archives of CivicAid data.
2. Created compressed tar.gz backups.
3. Created zip archives of log files.
4. Extracted archives into a restore test folder.
5. Improved scripts/backup_data.sh to create compressed backups.
6. Added scripts/archive_logs.sh for zipped log archives.
7. Verified backup restoration using tar extraction.

## Real-world meaning

Linux servers use archive and compression tools to store backups, move project files, compress logs, and prepare deployment packages.

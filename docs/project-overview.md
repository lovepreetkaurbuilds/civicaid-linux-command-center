# CivicAid Project Overview

CivicAid Linux Operations Command Center is a command-line operations system for a fictional NGO/community organization.

It manages fake/sample data for:

- public help requests
- volunteers
- donations
- service tickets
- reports
- logs
- backups
- automation
- server-style workflows

## Main purpose

The purpose of this project is to demonstrate practical Linux and Shell skills in a realistic project environment.

## Core features

- CSV-based operations data
- Daily and weekly report generation
- Searchable help requests
- Health check script
- Log monitoring
- Security audit
- Error diagnosis
- Backup and archive workflow
- Cron scheduled automation
- Local Python server with health endpoint
- Remote deployment simulation
- Menu-driven command center

## Important note

All data is fake/sample data only. No real private data or real secrets are used.

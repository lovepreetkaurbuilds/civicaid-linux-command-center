# Stage 24: Bash Customization

This stage customizes Bash for the CivicAid Linux Operations Command Center.

## Concepts learned

- aliases
- Bash functions
- .bashrc
- source
- prompt customization
- project shortcuts

## Shortcuts created

| Shortcut | Purpose |
|---|---|
| civi | Go to CivicAid project folder |
| civistatus | Show Git status |
| civitree | Show project tree |
| civireport | Generate daily report |
| civihealth | Run health check |
| civibackup | Create backup |
| civilogs | Show latest script logs |
| civilive | Watch logs live |
| civisummary | Generate summary reports |
| civisecurity | Run security audit |
| civicmd | Open CivicAid command center |
| civisearch | Search help requests |
| civiprompt_on | Turn on CivicAid prompt |
| civiprompt_off | Restore old prompt |

## Files created

| File | Purpose |
|---|---|
| ~/.civicaid_aliases | Local Bash customization file |
| config/civicaid_bash_aliases.example | GitHub-safe example of Bash shortcuts |

## Real-world meaning

Bash customization helps Linux users work faster by creating shortcuts for repeated project commands. Companies often use aliases, functions, and shell profiles to speed up common workflows.

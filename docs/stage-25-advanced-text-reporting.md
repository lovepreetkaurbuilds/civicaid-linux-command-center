# Stage 25: Advanced Text Processing and Reporting

This stage demonstrates advanced Linux text processing and report generation using CivicAid CSV and log files.

## Commands practiced

- grep
- grep -R
- grep -n
- awk
- sed
- sort
- uniq
- cut
- column
- wc
- tee

## Scripts created

| Script | Purpose |
|---|---|
| scripts/generate_summary_reports.sh | Creates a full CivicAid operations summary |
| scripts/generate_table_reports.sh | Creates readable table-style CSV reports |
| scripts/generate_log_summary.sh | Creates log error/warning/OK summaries |

## Reports created

| Report | Purpose |
|---|---|
| reports/civicaid_operations_summary.txt | Main operations summary |
| reports/help_requests_table.txt | Formatted help request table |
| reports/log_summary_report.txt | Log summary report |

## Practical tasks completed

1. Counted records across CivicAid CSV files.
2. Summarized help requests by category and status.
3. Calculated total donation amount using awk.
4. Summarized donations by method.
5. Extracted pending service tickets.
6. Created table-style reports using column.
7. Counted ERROR, WARNING, and OK log entries.
8. Generated professional report files from terminal commands.

## Real-world meaning

Advanced Linux text processing is useful for operations reporting, log analysis, CSV inspection, debugging, audits, and automation workflows.

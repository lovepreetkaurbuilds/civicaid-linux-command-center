# Stage 8: Linux Filesystem Structure

This stage explains the major Linux filesystem directories and how a real CivicAid deployment would use them.

## Directories learned

| Directory | Purpose |
|---|---|
| / | Root of the Linux filesystem |
| /home | User home directories and development workspaces |
| /bin | Essential command binaries |
| /usr | Installed programs and shared system files |
| /etc | System and application configuration |
| /var | Variable data such as logs, backups, and runtime files |
| /tmp | Temporary files |
| /opt | Optional or manually installed applications |
| /dev | Device files |
| /proc | Process and system information |

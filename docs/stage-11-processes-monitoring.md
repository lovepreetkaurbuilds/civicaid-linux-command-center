# Stage 11: Processes and System Monitoring

This stage demonstrates Linux process management and system monitoring using the CivicAid Linux Operations Command Center.

## Commands practiced

- ps
- top
- htop
- kill
- jobs
- fg
- bg
- &
- Ctrl+C
- Ctrl+Z
- uptime
- free
- df
- du

## Practical CivicAid tasks completed

1. Created a fake CivicAid worker process.
2. Ran the worker in the foreground.
3. Stopped a foreground process using Ctrl+C.
4. Ran the worker in the background using &.
5. Checked running processes using ps.
6. Saved a process ID into logs/fake_worker.pid.
7. Stopped a process safely using kill.
8. Practiced job control using jobs, bg, fg, Ctrl+Z, and Ctrl+C.
9. Checked system uptime, memory, disk space, and project folder usage.
10. Checked logs and backups disk usage.

## Real-world meaning

Linux process monitoring helps operators understand what is running, stop stuck processes, inspect resource usage, and prevent logs or backups from filling disk space.

# Linux and Shell Skills Proven by CivicAid

CivicAid Linux Operations Command Center is a practical Linux and Shell portfolio project that simulates operations workflows for a fictional NGO/community organization.

## Skills demonstrated

| Skill Area | Evidence in Project |
|---|---|
| Linux navigation | Project built and managed through terminal paths and commands |
| File management | Structured folders, files, configs, logs, reports, and backups |
| Text processing | grep, awk, sed, cut, sort, uniq, wc used on CSV/log data |
| Pipes and redirection | Reports generated from terminal pipelines |
| Permissions | Scripts made executable and config files protected |
| Users and access thinking | Role-based access model for admin, volunteer, finance, support |
| Process management | Fake worker process, process monitoring, stopping processes |
| Package management | Tools checked and installed using apt and command lookup |
| Python workflow | Python app, virtual environment, requirements.txt, pytest |
| Git/GitHub workflow | Version control, commits, branches, push/pull workflow |
| Environment variables | Safe config handling using env files and secret-safety rules |
| Shell scripting | Reusable Bash scripts for reports, backups, health checks, logs |
| Automation | Cron-based scheduled report and backup workflow |
| Backups | Compressed backup workflow using tar, gzip, zip, unzip |
| Networking basics | Local Python server tested with curl, wget, localhost, ports |
| Remote server workflow | Deployment simulation using Linux server-style folders and rsync |
| Logs and debugging | Log monitoring, ERROR/WARNING search, debugging workflow |
| Security basics | Security audit, secret checks, permission checks, sudo safety |
| Bash customization | Project aliases, functions, and command shortcuts |
| Troubleshooting | Common Linux errors documented with practical fixes |

## Summary

This project shows practical Linux and Shell ability through a realistic operations system, not isolated command practice.
